# Funcionalidad Area Incl.
01 Recepcion de alertas FLIC en tiempo real
Endpoint webhook que recibe SOS, caida, geocerca y bateria del boton FLIC via HTTP. Guarda log crudo, crea alerta y notifica por WebSocket.
 Backend ✓
02 Alta, edicion y baja de pacientes
CRUD completo: datos personales, domicilio, obra social, condiciones clinicas, medicacion, contactos de emergencia.
 Backend ✓
03 Alta y gestion de dispositivos (relojes FLIC)
Registro de cada reloj con su serial, asociacion al paciente, estado de bateria, ultima ubicacion conocida.
 Backend ✓
04 Autenticacion y roles de operadoras
Login con usuario y contrasena, JWT, roles (admin, operadora). Cada accion queda registrada con quien la hizo.
 Backend ✓
05 Gestion de alertas (atender, resolver, derivar)
La operadora toma la alerta, la marca como "atendiendo", registra acciones y la cierra como "resuelta". Log de auditoria completo.
 Backend ✓
06 Historial de alertas con filtros
Consulta de alertas pasadas por fecha, paciente, tipo, operadora. Exportable.
 Backend ✓
07 Dashboard de operadora en tiempo real
Cola de alertas en vivo, ficha del paciente con datos clinicos y contactos, copiloto con sugerencia de protocolo, log de actividad.
 Frontend ✓
08 Mapa con ubicacion GPS real
Mapa interactivo (Leaflet/OpenStreetMap) con la ubicacion del paciente al momento de la alerta, actualizado en tiempo real.
 Frontend ✓
09 Alarma sonora y notificacion visual
Sonido de alerta al recibir un SOS/caida, indicador visual parpadeante. Imposible que pase desapercibido.
 Frontend ✓
10 Pantalla de gestion de pacientes y dispositivos
ABM visual para cargar pacientes, asociar relojes, ver estado de cada dispositivo y editar datos.
 Frontend ✓
11 Pantalla de login y control de sesion
Formulario de login, manejo de sesion JWT, cierre automatico por inactividad.
 Frontend ✓
12 Despliegue en servidor de produccion
Docker Compose en VPS/cloud: backend, frontend, base de datos PostgreSQL, Redis, Nginx con SSL. Todo automatizado.
 Infra ✓
13 Dominio + HTTPS (certificado SSL)
Configuracion del dominio del cliente con certificado Let's Encrypt. Trafico encriptado. Renovacion automatica.
 Infra ✓
14 Backups automaticos de la base de datos
Backup diario automatizado de PostgreSQL. Retencion de 7 dias minimo.
 Infra ✓
15 Seguridad del sistema
Autenticacion de webhooks (API key), JWT en WebSocket, rate limiting, variables de entorno seguras, firewall basico.
 Seguridad ✓
