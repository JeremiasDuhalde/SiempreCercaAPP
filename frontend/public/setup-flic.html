Configurar boton FLIC

Guia para conectar el reloj al sistema de monitoreo

1
Abri la app FLIC

En el telefono del paciente, abri la app FLIC y selecciona el boton/reloj. Anda a la accion de Doble Click.

2
Agregar "Internet Request"

Toca el "+" para agregar una accion nueva. Busca "Internet Request" en la lista (puede estar en Tools o Hub Actions).

3
Copiar estos datos

Copia y pega cada campo tocando "Copiar":

URL
http://app.siemprecercasrl.net/api/webhooks/flic/alert
Metodo HTTP
POST
Content Type
application/json
Body
{"event": "sos"}
4
Agregar header de seguridad

En la seccion "HTTP Headers", agrega este header:

Key (nombre del header)
X-Webhook-Secret
Value (valor del header)
4d60192711902e66a26923bfc375cb73
Despues de pegar Key y Value, toca INSERT para confirmar. Si no tocas INSERT no se guarda.
5
Activar ubicacion

Abajo de todo en la pantalla, activa la opcion "Include location". Esto envia la ubicacion GPS cuando se toca el boton.

El "Request timeout" dejalo como esta (no tocar).

6
Guardar y probar

Guarda la accion y hace doble click en el boton del reloj.

Si todo esta bien, en el dashboard de Siempre Cerca va a aparecer la alerta con sonido y la ubicacion en el mapa.
