Configurar boton FLIC

Seguí estos pasos en la app FLIC del paciente

1 Abrir la app FLIC

Abri la app FLIC en el telefono del paciente y selecciona el boton/reloj. Anda a la accion de Doble Click.

2 Agregar accion "Internet Request"

Toca "+" para agregar accion. Busca "Internet Request" (puede estar en Tools o Hub Actions).

3 Configurar los campos

Copia y pega cada campo tocando el boton "Copiar":

URL
http://34.95.223.140/api/webhooks/flic/alert
Metodo HTTP
POST
Content Type
application/json
Body
{"event": "sos"}
4 Agregar header de seguridad

En HTTP Headers, toca para agregar un header:

Key
X-Webhook-Secret
Value
4d60192711902e66a26923bfc375cb73
Despues de pegar Key y Value, toca INSERT para confirmar el header
5 Activar ubicacion

Abajo de todo, activa "Include location" para que mande la ubicacion GPS.

El timeout dejalo como esta (default)
6 Guardar y probar

Guarda la accion y hace doble click en el boton. Si todo esta bien, en el dashboard de Siempre Cerca va a aparecer la alerta.
